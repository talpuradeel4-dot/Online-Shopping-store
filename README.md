# 🛒 Online Shopping Store in C++

A console-based Online Shopping Store developed using C++. This project allows users to browse products, add items to their shopping cart, manage quantities, view cart details, and generate a final bill.

## ✨ Features

- **Product Catalog:** Displays 10 products with their IDs, prices, and descriptions.
- **Add to Cart:** Select products using their IDs.
- **Quantity Management:** Automatically increases the quantity when the same product is added again.
- **View Cart:** Displays selected products, quantities, and prices.
- **Checkout and Billing:** Calculates the total cost of all selected items.
- **Input Validation:** Handles invalid product IDs and menu choices.
- **Formatted Output:** Displays product information and prices in an organized format.

## 🛠️ Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Standard Template Library (STL)
- `vector` and `string`
- Pointers and dynamic memory allocation
- Constructors, destructors, and virtual functions
- `iostream` and `iomanip`

## 📚 OOP Concepts

This project demonstrates encapsulation, classes and objects, constructors, destructors, and polymorphism through virtual functions.

### Classes

- `Product`: Stores product information.
- `Cart`: Manages selected products and their quantities.
- `Store`: Handles product display, cart operations, and checkout.

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project in a C++ IDE, such as Visual Studio or Dev-C++.

3. Compile the source file using a C++ compiler:

   ```bash
   g++ main.cpp -o shopping_store
   ```

4. Run the executable:

   ```bash
   ./shopping_store
   ```

   On Windows, run `shopping_store.exe`.

## 🎮 How to Use

After starting the program, use the following menu options:

| Option | Action |
|---|---|
| 1–10 | Add a product to the cart |
| 11 | View the shopping cart |
| 12 | Checkout and generate the bill |
